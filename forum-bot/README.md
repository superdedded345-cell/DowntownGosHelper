# Бот-наблюдатель за законами

Раз в сутки заходит на форум, сравнивает 43 закона с тем, что сейчас на сайте, и если что-то
изменилось, готовит обновление сайта и понятный отчёт: какая статья, что было, что стало.
По умолчанию бот НЕ меняет сайт сам: он создаёт Pull Request, вы смотрите отчёт и нажимаете
«Merge pull request». После этого GitHub Pages обновляет сайт, а игроки видят
«База законов обновлена».

## Установка (один раз, примерно 5 минут)

1. Откройте репозиторий DowntownGosHelper на GitHub.
2. Загрузите в корень репозитория папку `forum-bot` и папку `.github`
   (кнопка Add file -> Upload files, перетащите обе папки).
   Если папка `.github` не перетаскивается (она скрытая): Add file -> Create new file, в поле имени
   введите `.github/workflows/forum-monitor.yml` и вставьте туда содержимое одноимённого файла.
3. Разрешите боту создавать обновления: Settings -> Actions -> General -> внизу
   «Workflow permissions»: выберите «Read and write permissions» и поставьте галочку
   «Allow GitHub Actions to create and approve pull requests». Save.
4. Проверьте руками: вкладка Actions -> «Проверка законов на форуме» -> Run workflow.
   Зелёная галочка и надпись «Изменений нет» в отчёте означают, что всё работает.

## Как это выглядит дальше

- Нашлись изменения: появится Pull Request «Законы на форуме изменились» с отчётом.
  Прочитайте его и нажмите Merge. Новый index.html на сайт загружать не нужно.
- Бот не смог открыть тему или у темы пропала большая часть статей (форум поменял вёрстку,
  тема закрыта): такую тему бот НЕ трогает и создаёт Issue «Бот: проверьте форум».
- Форум блокирует бота полностью: запуск станет красным, и GitHub пришлёт письмо.
  Бот сначала пробует обычные запросы, потом настоящий браузер Chromium. Если не помогло,
  см. «Если форум блокирует» ниже.

## Настройки

- Время запуска: файл `.github/workflows/forum-monitor.yml`, строка `cron`. Время в UTC.
- Менять сайт сразу без Pull Request: Settings -> Secrets and variables -> Actions -> Variables ->
  New repository variable: имя `AUTO_COMMIT`, значение `true`. Не рекомендую: если форум отдаст
  мусор, он попадёт на сайт без вашей проверки (хотя защита от пустых и урезанных тем есть).
- Список тем: `forum-bot/sources.txt`.

## Если форум блокирует бота

Форум gta5rp.com уже отвечал ошибкой 403 скриптам, поэтому такое возможно и на GitHub.
Запасной вариант на вашем компьютере (форум открывается в вашем браузере):

1. Сохраните страницы тем из браузера (Ctrl+S, «Веб-страница полностью») в одну папку.
2. В папке forum-bot выполните:
   `pip install -r requirements.txt`
   `python monitor.py --site ../index.html --offline ПАПКА_С_СТРАНИЦАМИ --apply`
3. Прочитайте `report.md`, загрузите обновлённый index.html на GitHub.

## Что бот не умеет

- Не добавляет новые темы сам: если выйдет новый закон, добавьте ссылку в sources.txt и
  попросите пересобрать базу полностью.
- Не понимает смысл изменений, только сравнивает текст. Читайте отчёт перед Merge.
- Проверяет первое сообщение темы и подряд идущие сообщения-продолжения («Глава…», «Статья…»).
